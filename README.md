# Operation Restore (Health Program Evaluation) – Internship

## Description
Operation Restore is a post-traumatic rehabilitation program for emergency responders. As part of a collaborative research initiative between the Franciscan Center and the University of South Florida College of Public Health, I conducted a secondary evaluation of the program using survey and assessment data. I was responsible for data entry, cleaning, and statistical analysis using Qualtrics, Microsoft Excel, and SAS. The findings were translated into an evaluation report, a research poster, and an academic manuscript. 

Based on the evidence provided, the Franciscan Center’s executive board expanded the program to include other high-stress professions such as healthcare personnel, and began developing a tailored version to meet their specific needs.
